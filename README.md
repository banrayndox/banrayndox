### 🧠 Featured Repository: [Machine Learning & AI Curriculum (`ml_ai`)](https://github.com/banrayndox/ml_ai)

A comprehensive, self-paced, open-source learning path and proof of competence spanning from computational language basics to autonomous deep learning agents:

* 📚 **[01. Python Fundamentals](https://github.com/banrayndox/ml_ai/tree/main/01_Python_Fundamentals):** Complete 5-part curriculum with interactive Jupyter notebooks and lecture PDFs (Variables, Control Flow, Data Structures, OOP, File I/O & Exceptions).
* 📊 **[02. Data Science Toolkit](https://github.com/banrayndox/ml_ai/tree/main/02_Data_Science_Toolkit):** NumPy array computing, Pandas tabular wrangling, Matplotlib/Seaborn visualization, and automated web scraping.
* ⚙️ **[03. Classical Machine Learning](https://github.com/banrayndox/ml_ai/tree/main/03_Classical_Machine_Learning):** Regression (Linear from scratch, Lasso), Classification (Logistic, k-NN from scratch, SVM, Decision Trees, Naive Bayes), Ensemble (Random Forest, AdaBoost), and Unsupervised Clustering (K-Means, DBSCAN, PCA).
* 🧬 **[04. Deep Learning & Neural Networks](https://github.com/banrayndox/ml_ai/tree/main/04_Deep_Learning_Neural_Networks):** Perceptrons, Artificial Neural Networks (ANN), Convolutional Nets (CNN on CIFAR-10), Recurrent Nets (RNN Sentiment Analysis on IMDB), Generative Adversarial Networks (Vanilla GAN), Q-Learning/SARSA, and Vector RAG pipelines.
* 🚀 **[05. Applied Production AI Projects](https://github.com/banrayndox/ml_ai/tree/main/05_Applied_AI_Projects):**
  * **Flappy Bird DQN Game AI:** Autonomous reinforcement learning agent using Deep Q-Networks and replay memory.
  * **Text Summarizer Web App:** End-to-end NLP web service fine-tuned on the SAMSum dialogue dataset with Transformers.
  * **SmartCart Customer Segmentation & CreditWise Loan Systems:** E-commerce behavioral clustering and risk modeling.
